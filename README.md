# ⚽ ScoreCast | Live Sports Dashboard

A single-page web application that simulates **live football scores**, **match highlights**, and **league standings** — styled with a modern neon sports theme. Built with vanilla **HTML, CSS, and JavaScript**, this project demonstrates dynamic DOM updates, SPA-style navigation, and mock API simulations.

---

## 🚀 Features

- **Live Clock & Scoreboard**  
  - Real-time ticking match clock  
  - Animated score updates when goals are scored  
  - Syncs with simulated backend match data  

- **Secondary Matches**  
  - Dynamic cards showing other live matches  
  - League, teams, scores, and minutes updated every 10 seconds  

- **Highlights Section**  
  - Embedded YouTube videos converted safely into `iframe` embeds  
  - Responsive grid layout for video highlights  

- **League Standings**  
  - Mock standings table with team logos  
  - Stats: Matches Played, Wins, Draws, Losses, Goals For/Against, Goal Difference, Points  

- **SPA Navigation**  
  - Tabbed navigation between **Live Now**, **Highlights**, and **Standings**  
  - Smooth section switching without page reloads  

- **Styling**  
  - Dark neon theme with glowing accents  
  - Responsive design for desktop and mobile  
  - Animations for score changes and hover effects
